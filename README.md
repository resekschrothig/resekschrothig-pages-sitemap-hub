# resekschrothig GitHub Pages Sitemap Hub

这个仓库用于聚合 `resekschrothig` 账号下已经上线的独立 GitHub Pages 页面，方便把多篇 eSIM 推广内容整理成统一的抓取入口。

## 用途

- 为 Google 提供统一的 `sitemap.xml`
- 汇总多个独立页面的页面级 `sitemap.xml`
- 提供一个公开的 HTML 目录页，方便人工检查

## 当前收录主题

- 中国 eSIM
- 中国内地可用的 eSIM
- 香港 eSIM 在中国能用吗
- 中国 eSIM 热点共享
- 中国 eSIM 接短信 / 香港号码 eSIM
- 中国 eSIM 原生 IP 与更轻的隐私路径
- eSIM 国际网络与中国内地使用
- eSIM 替代 VPN / 梯子的稳定性研究
- 香港 IP eSIM 与原生 IP 场景
- eSIM 价格对比与测评
- eSIM 转实体卡教程
- 为什么需要 eSIM

## 公开入口

- 聚合目录页：`https://resekschrothig.github.io/resekschrothig-pages-sitemap-hub/`
- 站点地图索引：`https://resekschrothig.github.io/resekschrothig-pages-sitemap-hub/sitemap.xml`
- 页面 URL 列表：`https://resekschrothig.github.io/resekschrothig-pages-sitemap-hub/landing-pages.xml`

## 说明

本仓库不替代主站 `esimka.top` 自己的站点地图，而是作为 GitHub 独立页面矩阵的聚合入口。更理想的做法是把这里的 `sitemap.xml` 再提交到 Google Search Console，或在主站 `robots.txt` / 主站 sitemap index 中追加这一条聚合 sitemap。
